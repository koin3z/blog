VMX mode は「どのマシンか」、ring は「その中での権限」を表す別軸

VMX root — ホストの実行状態
VMX non-root — ゲストの実行状態

ホストのカーネル空間

Linux kernel + KVM

VM entry / exit、割り込み、メモリ仮想化を担う

ホストのユーザー空間

QEMU / libvirt

仮想デバイス、ファームウェア、VMのライフサイクル

ゲストのカーネル空間

ゲスト Linux kernel

ゲストのプロセス・仮想メモリ・仮想デバイスを管理

ゲストのユーザー空間

ゲストアプリケーション

通常の system call は右列の中で完結する

system call
KVM_RUN

通常: app → guest kernel（system call） / 捕捉時: guest ↔ KVM（VM exit / entry）

「ring -1」は便宜上の呼び名。VMX root / non-root を ring 0〜3 の番号に置き換えない。
