# 図解パターン

## 選択表

| 読み取らせたい関係       | パターン         | 主な配置                             |
| ------------------------ | ---------------- | ------------------------------------ |
| 時間、成熟、処理の前進   | コンパクトな工程 | 横一列のノードと細い矢印             |
| 責任や抽象度の積み重なり | レイヤー         | 縦積みカード、下向きまたは双方向矢印 |
| 選択肢の違い             | 比較             | 同幅の列と共通の比較軸               |
| 中心機能と周辺機能       | ハブ・スポーク   | 中央ノードと放射状の周辺ノード       |
| 少数の分類と所属項目     | コンパクトな群   | 3〜4個の外箱と内部の短いラベル       |
| 状態と条件分岐           | フロー           | 開始、処理、判断、終了を形状で区別   |
| 時点ごとの出来事         | タイムライン     | 1本の軸と交互または片側のイベント    |

関係が複数混ざる場合は主たる読み方を1つ選ぶ。
補助関係は注釈へ移し、異なる読み順を同じ図に重ねない。

## プリミティブの選択

| 意味                   | 先に検討する表現             |
| ---------------------- | ---------------------------- |
| 順序、前後関係         | 線、小さなノード、直接ラベル |
| 包含、所有             | 必要な範囲だけの外枠         |
| 近接する分類           | 余白、整列、短い群ラベル     |
| 共通軸による比較       | `table`                      |
| 独立した状態、責任境界 | 平面的なボックス             |

位置と線だけで意味が読める場合は、カード、注釈箱、背景パネルを追加しない。
パターンは配置構造として使い、作例の色を共通スキンとして転用しない。

## コンパクトな工程

[完成したHTML作例](../assets/examples/progression-with-notes.html)

[背景透過PNGの作例](../assets/examples/progression-with-notes.png)

### 適用条件

- 3〜5段階が同じ粒度で並ぶ
- 左から右へ進む意味がある
- 各段階をタイトルと短い1行で表せる
- 各段階の補足を比較する必要がある場合だけ、小さな下段ラベルを付ける

### 構造

```text
    ● ─────────▶ ● ─────────▶ ●
  title         title         title
  detail        detail        detail
  [note]        [note]        [note]
```

- 小さなノードとコネクターを背面SVGへ置き、ラベルをGridで揃える
- 配置先の明暗が不明な場合は、文字の背面だけに選択した主色の小さな淡色面を置く
- 段階全体を大きなカードへ入れない
- 補足に境界が必要な場合だけ、小さなラベルとして囲う
- 色だけで順序を示さず、矢印を必ず置く
- 補足ラベルは対応するノードと同じ列に置く
- 図全体の見出し専用領域は作らない

### 避ける条件

- 段階ごとに情報量が大きく異なる
- 6段階以上を1行へ押し込む必要がある
- 分岐や循環が主題である

## レイヤー

[完成したHTML作例](../assets/examples/compact-layer-stack.html)

[背景透過PNGの作例](../assets/examples/compact-layer-stack.png)

### 適用条件

- 上位から下位、利用側から基盤側など、安定した層序がある
- 各層の責任と代表要素を並べたい

### 構造

```html
<section class="grid gap-3">
  <article
    class="grid grid-cols-[180px_1fr] items-center rounded-2xl border-2 border-[#60A5FA] bg-[#1E40AF] px-6 py-4 text-white"
  >
    <h2 class="text-[22px] font-bold">Presentation</h2>
    <p class="text-[18px] leading-relaxed">画面、入力、表示状態</p>
  </article>
  <div class="flex justify-center" aria-hidden="true">
    <!-- 下向きのインラインSVG矢印 -->
  </div>
  <!-- 次の層 -->
</section>
```

- 層名の列幅を揃える
- 依存方向と呼び出し方向が異なる場合はラベルを付ける
- 代表コンポーネントを層名と同じ見た目にしない
- 役割が異なる層を複数色で示す場合は、明度と彩度を揃える

## 比較

### 適用条件

- 3〜4個の候補を共通の軸で比較する
- 読者が選択または位置付けを判断する

### 構造

- 共通の比較軸がある場合は、HTMLの`table`を既定にする
- 候補ごとの内部構造が異なる場合だけ、同幅の列を使う
- 各候補で比較軸の順序を揃える
- 推奨候補がある場合は、色だけでなく短いバッジで示す
- 欠点を赤だけで表さず、`制約`や`不向き`のラベルを付ける

表で表せる関係を、装飾目的のカード列へ置き換えない。

## ハブ・スポーク

[完成したHTML作例](../assets/examples/hub-and-spoke.html)

[背景透過PNGの作例](../assets/examples/hub-and-spoke.png)

### 適用条件

- 中心に1つの調整役、共有基盤、または境界がある
- 周辺要素同士の直接関係は主題ではない

### 構造

- 中心ノードをキャンバス中央へ置く
- 周辺ノードを4〜7個に抑える
- コネクターは中心の背面へ置き、カードの下へ潜らせる
- 周辺ノードの位置に意味がない場合は等間隔にする
- 周辺ノードはタイトルと短い1行にし、同じ寸法へ揃える
- 周辺ノードは同じ有彩色パレット、彩度、文字階層へ揃える
- 周辺の分類、責任、状態に意味がある場合、または参照構成が多色の場合だけ色相を分ける
- 線は関連なら矢じりなし、方向や因果がある場合だけ矢印にする
- 中央円を大きくしすぎず、周辺ノードと線の判読に必要な寸法へ留める

## コンパクトな群

[完成したHTML作例](../assets/examples/compact-command-groups.html)

[背景透過PNGの作例](../assets/examples/compact-command-groups.png)

### 適用条件

- 3〜4個の分類と、各分類に2〜4個の短い項目がある
- 分類間の順序や因果ではなく、所属関係を読ませたい
- 凡例、コマンド一覧、責任範囲の小図として本文中へ置きたい

### 構造

```text
┌──────────┐  ┌──────────┐  ┌──────────┐
│ group A  │  │ group B  │  │ group C  │
│ [item]   │  │ [item]   │  │ [item]   │
│ [item]   │  │ [item]   │  │ [item]   │
└──────────┘  └──────────┘  └──────────┘
```

- 外箱と内部ラベルは同色相の明度差で分ける
- 外箱の色相は白、灰、黒ではなく有彩色を選ぶ
- 外箱の幅、高さ、内部の間隔を揃える
- 線で関係を示す必要がなければ、コネクターを追加しない
- 各項目が長文になる場合は、群ではなく比較表または別図を選ぶ

## フロー

### 形状

| 種別       | 形                             |
| ---------- | ------------------------------ |
| 開始、終了 | カプセル                       |
| 処理       | 角丸長方形                     |
| 判断       | ひし形または明示的な分岐カード |
| 外部主体   | 枠線付きカード                 |

- ステップ番号を使う場合は矢印方向と一致させる
- 分岐ラベルはコネクターの近くへ置く
- 戻り線が主経路を横切る場合は別図へ分ける

## タイムライン

- 軸は1本にする
- 日付または時点を同じ位置に揃える
- 出来事、結果、未解決事項を別の文字階層で表す
- 時点数が多い場合は期間単位で分割する
